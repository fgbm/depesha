# Критерии приёмки рефакторинга фронтенда (issue #48)

Зеркало критериев issue #48. Рефакторинг принимается, когда выполнены все критерии с пометкой **[обяз.]**; **[жел.]** — желательно и не блокирует. В колонке «Проверка» указано, как критерий подтверждается: **авто** — автотест или скрипт, **CI** — шаг в GitHub Actions, **ручн.** — ручная проверка.

Цель работы — поведение-сохраняющий рефакторинг по фазам, без новых функций. Фазы и их DoD — ниже, после критериев.

## Инварианты

| № | Критерий | Проверка |
| --- | --- | --- |
| AC1 | **[обяз.]** Поведение не меняется: ни одной новой/изменённой функции, сообщения, клавиши, настройки. | ручн., E2E |
| AC2 | **[обяз.]** `e2e/run.mjs` не изменён рефакторингом (diff пуст с фазы 0), все 78 шагов зелёные. | авто (`git diff`), E2E |
| AC3 | **[обяз.]** Ни один тест не удалён и не ослаблен; `vitest run` зелёный. | авто |
| AC4 | **[обяз.]** `svelte-check --fail-on-warnings` чист; `cargo fmt/clippy/test` без изменений. | авто, CI |
| AC5 | **[обяз.]** Набор используемых компонентами членов `app.*` идентичен baseline (85). `@depesha/plugin-api` не меняет своё поведение; единственное добавление за релиз — `scheduleReload()` для задемпференной перезагрузки плагинных списков (задача #37). | авто (`frontend-invariants.sh`), CI |
| AC6 | **[обяз.]** Нет новых рантайм-зависимостей (линтер — только в `devDependencies`). | CI (`npm ci` + `dependencies`), ручн. |
| AC7 | **[обяз.]** Критерий безопасности 8.5 (CSP, «каждое окно — только свои команды») выполнен. | авто (тесты), ручн. |

## Критерии приёмки по фазам (DoD)

| Фаза | Принимается, когда | Проверка |
