# Отчёт о приёмке Депеши 0.2.0

Дата: 2026-10-03. Критерии — [acceptance.md](acceptance.md).

Как проверялось:

- **E2E** — `e2e/run.mjs`: настоящее приложение на виртуальном дисплее (Xvfb), управление по WebDriver, сервер GreenMail. 45 из 45 шагов в 0.5.0, включая плагины и песочницу сторонних плагинов; в тёмной теме сценарий последний раз проходил в 0.4.0 (39 шагов).
- **IT** — интеграционные тесты ядра: GreenMail (`tests/greenmail.rs`, 6) и Dovecot 2.4 (`tests/dovecot.rs`, 5).
- **EX** — сценарный SMTP-сервер с ответами Exchange 2019 (`tests/exchange_smtp.rs`, 6).
- **PERF** — ящик Dovecot на 50 000 писем (`tests/perf.rs`, release-сборка).
- **UT** — юнит-тесты: Rust 33, фронтенд 20.

Всё запускается одной командой `scripts/check.sh`.

## Открытые вопросы

1. Нужен прогон на живом Exchange 2019 по сценарию из [acceptance.md](acceptance.md).
2. TLS-стек rustls поддерживает только AEAD-наборы шифров (GCM, ChaCha20). Сервер, ужесточённый до CBC-наборов, не подключится.
3. NTLM и Kerberos не реализованы. Сервер, который предлагает только их, получает понятное сообщение, но отправка через него невозможна.
