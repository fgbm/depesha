# Депеша 0.8.18

В этом выпуске появился необязательный плагин «Типографика» для замен при наборе письма. Также исправлены чтение больших писем и фоновая синхронизация папок.

## Новое

### Плагин «Типографика»

Плагин включается в «Настройки» → «Плагины» и по умолчанию выключен. Он делает ровно две замены: `--` превращается в длинное тире `—`, а `...` — в многоточие `…`.

Замены работают при наборе в обычном тексте, HTML и Markdown. Уже написанные черновики и вставленный текст не переписываются. В Markdown не меняются блоки кода и строки из одних дефисов, а в HTML — код, ссылки и подпись, которую нельзя править. Плагин можно включить или выключить при открытом окне письма: новое поведение действует со следующей клавиши.

## Исправлено

### Чтение письма не обрывается на длинной загрузке

Открытие другого письма сразу отменяет чтение тела, которое больше не нужно, вместо ожидания ответа прошлого сервера. Для открытого письма заданы короткие окна первого ответа и тишины между байтами. При этом у активной загрузки по IMAP больше нет общего пятнадцатиминутного предела: большое письмо, которое продолжает качаться, не теряет уже полученные данные на пятнадцатой минуте. Если сервер замолчал, чтение завершается ошибкой без повторного захода, который снова держал бы очередь ящика.

### Автоматическая синхронизация не мешает работе

Синхронизация при открытии папки больше не держит общий индикатор загрузки и не встаёт впереди действий пользователя. Она выполняется в фоне, не снимает паузу сети и не повторяет подключение, если действие пользователя уже поставило ящик на паузу. Тихая работа, ожидавшая в очереди, перепроверяет паузу непосредственно перед обращением к серверу.

### Текст страницы ящика не теряется при скрытии окна

Если окно было скрыто без нового события потери фокуса, набранное на странице ящика могло остаться несохранённым. Теперь такое поле сохраняется и по событию `visibilitychange`, поэтому текст не пропадает при скрытии окна в любом состоянии фокуса.

## Откат на 0.8.17

Формат кэша и настроек не менялся, миграций базы нет. Версия 0.8.17 откроет кэш как есть; плагина «Типографика» в ней нет, поэтому его замены при наборе перестанут действовать.
