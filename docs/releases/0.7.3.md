# Депеша 0.7.3

Это исправительный выпуск после 0.7.2. Файл, перетащенный в окно письма на Windows, снова прикрепляется. «Без напоминания» больше не отправляет письмо в «Ждут ответа». Вид чтения, заданный у человека или у ящика, теперь применяется к письму.

## Исправлено

### Перетаскивание файла в окно письма на Windows

Файл, перетащенный в окно письма, снова прикрепляется (#79). Причина была в том, что окно спрашивало о файле раньше, чем приложение разрешало его использовать. Файл прикрепляется только в том окне, куда его бросили.

В отдельном окне письма перетаскивание пока не работает. Это будет исправлено в следующем выпуске (#107).

### «Без напоминания» и «Ждут ответа»

Ответ с выбором «Без напоминания» больше не отправляет исходное письмо в «Ждут ответа» (#106). Ожидание ответа включается только выбранным сроком напоминания.

Галочка «Убрать письмо из входящих» переносит исходное письмо в архив вместе с прочитанными письмами этой переписки. Если у ящика нет папки архива, галочка недоступна.

Уведомление «Отправлено» приходит сразу. Когда перенос закончится, появляется второе: «Письмо — в архиве · Отменить».

На странице ящика эта настройка теперь называется «Убирать письмо из входящих после ответа».

Ответы, которые на момент обновления ещё стояли в очереди отправки с прежним «ожиданием без срока», уйдут не в «Ждут ответа», а в архив, если у ящика включена эта настройка.

Кнопка «Отменить» в уведомлениях о переносе отменяет именно тот перенос, к которому относится уведомление, и только один раз.

### Вид чтения

Вид чтения, заданный у человека или у ящика, теперь применяется к письму (#105). Порядок старшинства такой: сначала выбор, сделанный вручную над письмом, затем вид человека, затем вид ящика, затем общая настройка.
