# Депеша 0.7.4

Это исправительный выпуск после 0.7.3. Перетаскивание файлов во вложения снова работает и в главном окне, и в отдельном окне письма. Если вложенный файл к моменту отправки исчез, вы увидите понятную ошибку.

## Исправлено

### Перетаскивание файлов во вложения

В 0.7.3 перетащенный файл не прикреплялся ни в главном окне, ни в отдельном окне письма, и приложение об этом молчало (#79, #107). Теперь файл прикрепляется в обоих окнах. Он попадает в то окно, куда его бросили.

Если файл всё же не приложился, в журнале видно, на каком шаге это оборвалось. Имена файлов в журнал не попадают, только их количество.

### Проверка вложений при отправке

Если приложенный файл к моменту отправки исчез или стал папкой, письмо не уйдёт с пустым вложением. Вместо этого придёт понятная ошибка с указанием файла. То же относится к картинкам, которые вставляются в текст письма.
