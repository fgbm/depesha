# Депеша 0.8.20

Патч исправляет сбои при отправке писем и синхронизации папок.

- Если почтовый сервер не подтвердил приём письма, Депеша оставляет его в «Исходящих» с пометкой «возможно, ушло». Перед повторной отправкой можно проверить письмо в «Отправленных».
- При неполном или противоречивом ответе IMAP Депеша сохраняет уже загруженные письма в папке.
- Если сервер молчит при включении шифрования, Депеша завершает ожидание по таймауту. На ответ IMAP STARTTLS и на TLS-рукопожатие отводится по 20 секунд.
