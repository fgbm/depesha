# Депеша 0.8.10

Выпуск о метках на Exchange: их можно ставить. На ящике, подключённом по Exchange Web Services, установка метки падала с `Exchange ответил ErrorInvalidRequest: The request is invalid.`

## Исправлено

### Метка на Exchange по EWS

Запрос на запись категории содержал два неверных элемента. Поле называлось `message:Categories`, а в EWS категории живут в `item:Categories`: такого поля сервер не знает и отвечает `ErrorInvalidRequest`. Добавление шло через `AppendToItemField`, который для категорий Exchange тоже не принимает.

Теперь метка ставится так же, как снимается: программа читает категории письма с ключом изменения, дополняет список и записывает его целиком. Если категорию одновременно изменил Outlook, запись повторяется на свежем чтении, чужая правка не теряется. Ошибка чтения, кроме исчезнувшего письма, больше не превращается в «нечего менять», а метка в кэше появляется только у писем, которым сервер её действительно записал.

## Ограничение

При перемещении письма в другую папку метка не переезжает — отдельная задача, #201.

## Откат на 0.8.9

Откат возможен: формат кэша не менялся.
