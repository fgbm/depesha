# Словарь терминов

Один термин — одно значение. Синонимы запрещены. Пиши термин так, как он назван здесь.

Каждый термин — заголовок второго уровня. Под ним три строки: определение, запрещённые синонимы, имя в коде. Строку «Синонимы (запрещены)» читает `scripts/ste-lint.mjs`; список веди в том же виде.

Раздел «Не писать» — пустые слова. `ste-lint` даёт на них ошибку, как на запрещённый синоним.

## курсор списка

- Определение: письмо в списке, на котором стоит клавиатурный фокус; клавиши действуют на него.
- Синонимы (запрещены): «текущее письмо», «выделенное письмо».
- В коде: `cursor`, `cursorId`, класс `.row.cursor`.

## каретка

- Определение: позиция ввода в текстовом поле или редакторе.
- Синонимы (запрещены): «текстовый курсор».
- В коде: нет имени в коде.

## выбор

- Определение: набор отмеченных писем, над которыми действует панель действий.
- Синонимы (запрещены): «выделение», «селекция».
- В коде: `selection`, `SelectionController`, `app.selection`, класс `.row.selected`.

## письмо

- Определение: одно сообщение электронной почты.
- Синонимы (запрещены): «сообщение», «мейл».
- В коде: `message`, `MessageRow`; местами `letter` (`LetterViewSwitch.svelte`).

## цепочка

- Определение: письма одной переписки, собранные вместе.
- Синонимы (запрещены): «беседа», «тред».
- В коде: `thread`, `Conversation.svelte`; в английском интерфейсе — `conversation`.

## ящик

- Определение: почтовый аккаунт пользователя в Депеше.
- Синонимы (запрещены): «учётная запись», «аккаунт».
- В коде: `account`, `MailboxController`, `app.mailboxes`.

## папка

- Определение: место хранения писем на сервере и в Депеше.
- Синонимы (запрещены): «директория».
- В коде: `folder`, `folders.ts`.

## метка

- Определение: пользовательская пометка письма или папки.
- Синонимы (запрещены): «тег».
- В коде: `label`, `labels.svelte.ts`.

## читалка

- Определение: область окна, где читается открытое письмо.
- Синонимы (запрещены): «просмотрщик», «вьюер».
- В коде: `reader`, `reader.svelte.ts`, `Reader.svelte`.

## список

- Определение: перечень писем выбранной папки.
- Синонимы (запрещены): «листинг».
- В коде: `list`, `list.svelte.ts`, `MessageList.svelte`.

## панель действий

- Определение: полоса кнопок над списком и читалкой; действует на курсор или выбор.
- Синонимы (запрещены): «тулбар», «панель инструментов».
- В коде: `ReaderToolbar.svelte`, `ReaderStates.svelte`.

## Исходящие

- Определение: папка с письмами, которые ждут отправки.
- Синонимы (запрещены): «аутбокс».
- В коде: `outbox`, `Outbox.svelte`, ключ `nav.outbox`.

## задача

- Определение: фоновая работа Депеши — синхронизация, скачивание, очистка.
- Синонимы (запрещены): «джоб».
- В коде: `tasks`, `background.svelte.ts`, ключ `tasks.title` («Фоновые задачи»).

## плагин

- Определение: расширение Депеши за пределами приёма и отправки почты.
- Синонимы (запрещены): «аддон», «расширение».
- В коде: `plugin`, `plugins/`, `src/plugin-api/`.

## макет

- Определение: HTML-файл с вариантами интерфейса для выбора оператором.
- Синонимы (запрещены): «мокап», «прототип».
- В коде: `design/mockups/<версия>/`.

## живой макет

- Определение: фронтенд Депеши в браузере с подставным бэкендом и демо-данными.
- Синонимы (запрещены): «демка».
- В коде: `src/demo/`, команды `npm run demo` и `npm run demo:build`.

## вариант

- Определение: один из предложенных ответов на вопрос макета (А, Б, В).
- Синонимы (запрещены): «опция».
- В коде: `variant()`, `src/demo/variants.svelte.ts`.

## решение

- Определение: выбор оператора по вопросу макета, записанный в `decisions.md`.
- Синонимы (запрещены): «вердикт».
- В коде: `design/mockups/<версия>/decisions.md`.

## оператор

- Определение: человек, который ставит задачи и принимает решения.
- Синонимы (запрещены): «заказчик», «владелец».
- В коде: нет имени в коде.

## worktree

- Определение: отдельная рабочая копия репозитория для одной ветки.
- Синонимы (запрещены): «ворктри».
- В коде: `git worktree`, каталог `/home/vch/Projects/depesha-wt/<имя>`.

## основное дерево

- Определение: главный checkout репозитория, только для слияний.
- Синонимы (запрещены): «главное дерево», «мастер-дерево».
- В коде: `/home/vch/Projects/depesha`.

## стенд

- Определение: общий для всех worktree набор контейнеров GreenMail и Dovecot с виртуальным дисплеем.
- Синонимы (запрещены): «полигон».
- В коде: `compose.test.yaml`, `scripts/stand-lock.sh`.

## ревью

- Определение: разбор диффа ветки до слияния.
- Синонимы (запрещены): «обзор кода».
- В коде: агент `reviewer`.

## Не писать

Пустые слова. `ste-lint` даёт на них ошибку, как на запрещённый синоним. Слово в кавычках, в `коде` и в блоке кода не проверяется.

- Канцелярит: «является», «осуществлять», «производить», «данный», «в целях», «в рамках», «на предмет», «имеет место», «в случае если».
- Размытые указания: «следует», «желательно», «по возможности», «при необходимости», «как правило», «рекомендуется».
- Пустые вступления: «Знай:», «Знай устройство:», «Помни:», «Обрати внимание», «Важно:», «Стоит отметить».
