# Задание для `coder`

Шаблон задания агенту `coder`. Заполняй блоки по порядку. Пиши по правилам письма: одно правило — одна строка, инструкция — не длиннее 20 слов.

## Цель

Одно предложение: что меняется и зачем.

## Запреты

Общий список — `AGENTS.md`, раздел «Запреты»; не копируй его сюда. Допиши запреты задачи: что нельзя менять и какие файлы не трогать.

## Шаги

1. Прочитай перечисленные файлы.
2. Внеси правку по спецификации.
3. Запусти проверки.

## Проверки

Перечисли точные команды и ожидаемый результат. Пример: `scripts/check.sh --changed` — зелёный.

## Отчёт

- Что сделано — одна фраза.
- Файлы — путь и строка, что изменилось.
- Проверки — команды и результат.
- Открытые вопросы — что не проверено или спорно.
