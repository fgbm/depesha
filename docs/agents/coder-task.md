# Задание для `coder`

Шаблон задания агенту `coder`. Заполняй блоки по порядку. Пиши по правилам письма: одно правило — одна строка, инструкция — не длиннее 20 слов.

## Цель

Одно предложение: что меняется и зачем.

## Запреты

Общий список — `AGENTS.md`, раздел «Запреты»; не копируй его сюда. Допиши запреты задачи: что нельзя менять и какие файлы не трогать.

## Шаги

1. Прочитай перечисленные файлы.
2. Внеси правку по спецификации.
3. Запусти проверки.

## Проверки

Перечисли точные команды и ожидаемый результат. Пример: `scripts/check.sh --changed` — зелёный в ходе работы и перед слиянием в `main`; `scripts/check.sh --ci` — необязательно, для рискованной правки.

## Готово, когда

- Проверки зелёные, правка слита, как велит задание.
- Worktree удалён вместе с `target`. Если он остался, `target` удалён (`rm -rf target`). Почему: брошенные `target` по 3 ГБ забивают диск.
- В отчёте есть `git worktree list` и `df -h /home`.

## Отчёт

- Отчёт — один раз, в конце задания, без промежуточных возвратов. Почему: каждое возвращение агента дорого стоит оркестратору.
- Кадры — одним HTML с картинками base64 и подписями. Почему: картинки ссылкой в чате оператор не видит.
- Что сделано — одна фраза.
- Файлы — путь и строка, что изменилось.
- Проверки — команды и результат.
- Открытые вопросы — что не проверено или спорно.
