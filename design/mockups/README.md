# HTML-макеты

Макеты лежат по версиям: `design/mockups/<версия>/NN-имя.html`. Каждый макет — самодостаточный одиночный файл: без сети и внешних ссылок, оператор скачивает его и открывает локально (`file://`).

## Панель «Ответы»

Набор `design/mockups/_kit/` (`answers.js`, `answers.css`) добавляет к макету боковую панель: оператор отмечает варианты и пишет комментарии прямо в макете, внизу панели собирается сводка для отправки.

Что умеет:

- кнопка «Выбрать 1.1 А» рядом с каждым вариантом на макете, выбранный вариант подсвечен; поле комментария к вопросу рядом;
- несколько вариантов («А+В») — `Shift`+щелчок; «свой» — ответ текстом;
- заметка с номером-меткой: кнопка «📌 Заметка» или клавиша `N` (`Т` на русской раскладке) при фокусе в панели, затем щелчок по макету (курсор-прицел, `Esc` — отмена); `Alt`+щелчок по любому месту работает так же, но на части Linux его перехватывает оконный менеджер; в сводке она привязана к экрану, ближайшему вопросу или варианту и цитате элемента;
- панель: список вопросов с вариантами и рекомендацией (★), счётчик «отвечено N из M», «Взять рекомендации для неотвеченных», сводка и «Скопировать», экспорт и импорт JSON, «Сбросить» (с подтверждением);
- панель не перекрывает макет: пока она открыта, страница сдвигается влево на её ширину (372 px), а макеты шире свободного места (`.doc` 1180 и 1400 px) уменьшаются, чтобы правый край и верхняя панель переключателей остались видны; закреплённые справа элементы (`position: fixed`) сдвигаются вместе со страницей. Свёрнутая панель — язычок «Ответы · 3/19» у правого края. Уже 1100 px панель открывается поверх страницы и по умолчанию свёрнута; состояние «открыта/свёрнута» запоминается;
- ответы и заметки хранятся в `localStorage` по имени файла и переживают перезагрузку.

Клавиши:

- `` ` `` (на русской раскладке `ё`) — показать или свернуть панель; не срабатывает в полях ввода и в живых окнах макета (`.stage`, элементы с `tabindex`), чтобы не мешать их клавишам;
- в панели: `↑` `↓` — по вопросам, `А` `Б` `В` (или `1` `2` `3`) — выбрать вариант, `Shift`+буква — добавить или снять вариант, `Enter` — комментарий, `Esc` — назад к списку (из списка — свернуть), `Del` — очистить ответ;
- `N` (`Т`) — режим заметки, `Esc` — отменить его (в панели);
- в окне заметки: `Ctrl+Enter` — сохранить, `Esc` — закрыть.

Формат сводки:

```
Макет: 01-settings.html
1.1 А — коммент
1.2 свой: …
Без ответа: 2.3, 4.1
Заметки:
- [экран 2, 2.1 Б «Система»] коммент
```

## Как размечать макет

Набор находит вопросы и варианты по атрибутам:

- `data-q="1.1"` — блок вопроса или экрана. На строке таблицы «Вопросы» (`<tr>`) он описывает вопрос целиком, на заголовке вопроса на экране добавляет рядом поле комментария;
- `data-q-title="Выбор из нескольких"` — название вопроса для панели;
- `data-variants="А,Б,В"` — какие варианты есть у вопроса (нужно, если на экранах нарисованы не все);
- `data-recommended="Б"` — рекомендация (берётся кнопкой «Взять рекомендации»);
- `data-variant="А"` вместе с `data-q` — блок варианта в любом месте страницы, обычно его заголовок; кнопка выбора вставляется в начало блока;
- `data-q-closed` — вопрос снят: в панели он затемнён и не входит в счётчик и «Без ответа».

Пример строки таблицы «Вопросы» и заголовка варианта:

```html
<tr data-q="1.1" data-q-title="Правило для выбора" data-variants="А,Б,В" data-recommended="А">…</tr>
<h3 data-q="1.1" data-variant="Б" class="v">…</h3>
```

Номера вопросов после публикации не меняются. Буквы вариантов пишите кириллицей, как в тексте макета.

## Как вставить набор

```
node scripts/mockup-kit.mjs design/mockups/0.8.0/*.html
```

Скрипт кладёт стили и код набора в макет перед `</body>`, между маркерами `<!-- mockup-kit:start -->` и `<!-- mockup-kit:end -->`. Повторный запуск заменяет вставку, так что после правки `_kit/` достаточно прогнать скрипт ещё раз. Сами файлы набора в макете руками не правят. Новый макет: разметьте вопросы и варианты, запустите скрипт, откройте файл и проверьте панель.
