#42 — Метки, права на папки и возможности отдельных папок

Продолжение #11. В 0.6.0 раздел «Сервер» на странице IMAP-ящика показывает возможности сервера для ящика целиком. Здесь — то, что зависит от папки: можно ли в ней хранить свои метки (PERMANENTFLAGS), что разрешено вам в общей или чужой папке (MYRIGHTS, [READ-ONLY], NAMESPACE), как это видно в сайдбаре и что происходит при запрещённом действии. Плюс безопасная проверка меток на тестовом письме. Сведения о папке собираются при её открытии или по кнопке, а не обходом всех папок при каждом запуске. Ничего из этого не меняет письма, кроме проверки на тестовом письме, и та только по явной просьбе.

Метки в строке письма и их выбор (кадр 10) — на границе задачи: в #42 их нет, но #11 требует подписи «Сохраняется на сервере / Только на этом устройстве / Серверное сохранение не подтверждено» именно в интерфейсе меток. Нарисованы, чтобы решить, входят ли они в 0.7.

Папки новое: варианты в кадрах 2–3

…
  • 1Строки «Права на папки» и «Общие папки» в 0.6.0 говорят «Депеша права пока не показывает» — теперь показывает, тексты меняются, структура таблицы та же: новая функция — строка FEATURES и тексты в локалях.
  • 2Если у сервера нет ACL, строка уходит в «Нет на сервере» со строкой «Без этого…»: «Депеша узнаёт о запрете, только когда сервер откажет. Папку только для чтения видно при её открытии». Без NAMESPACE общие папки остаются в общем списке.
  • 3«Свои метки» в колонке «Сервер» — «зависит от папки» с полузакрашенной точкой: это не «есть» и не «нет». Счёт «6 из 8 проверенных» честно говорит, что непроверенные не учтены. Если не проверено ни одной папки — «узнаем при открытии папки».
  • 4Жёлтая точка у «Сервер» в оглавлении остаётся только для IDLE и MOVE, как решено в 0.6.0: папка только для чтения — не проблема сервера.

9Проверка меток на тестовом письме

По кнопке «Проверить метки на тестовом письме…» из подраздела «Папки» (кадр 2) или из свойств папки. Обычное определение ничего не пишет на сервер; эта проверка пишет — поэтому сначала окно с тем, что именно произойдёт. Слева — перед проверкой, справа — итог: PERMANENTFLAGS обещал \*, но сервер метку не сохранил.

Проверить метки во «Входящих»?

Сервер говорит, что свои метки в этой папке сохраняются. Проверим на деле:

  1. положим во «Входящие» тестовое письмо «Депеша: проверка меток» — от вас самому себе, без отправки;
  2. поставим ему метку, отключимся и прочитаем её заново;
  3. удалим тестовое письмо.

Ваши письма не меняются. Займёт несколько секунд. Если проверка прервётся, тестовое письмо может остаться — его можно удалить.
