# Спайк 01. Значок в трее и уведомления (0.7, #4 / #63)

Записка спайка: что проверили и чем ограничена платформа. Код спайка в репозиторий не попадает.

## Значок в трее

- Трей — `tray-icon` с бэкендом `ksni` вместо libappindicator: нет системной зависимости, и левый щелчок приходит в приложение (через appindicator Tauri его не получает).
- На GNOME без расширения трея значка нет. `build()` возвращает ошибку `ServiceUnknown` — это и есть признак отсутствия трея, по нему решаем, предупреждать ли пользователя.
- Подписи-числа у значка нет: число рисуется прямо на иконке. `set_badge_count` есть на Linux (Unity), на Windows такого метода нет.

## Окно и фон

- Крестик окна — `prevent_close` + `hide`: окно не уничтожается, потому что правила и плагины живут во фронтенде, а не в бэкенде.

## Уведомления

- Linux — `notify-rust`, действие `default` (щелчок по уведомлению).
- Windows — `tauri-winrt-notification` с `on_activated`; `notify-rust` там не годится. AppUserModelID проставляет бандлер.
- Щелчок по уведомлению уже закрытого приложения на Windows возможен только через протокол и deep-link — отложено.

## Риски

- Окно на Wayland может не подняться на передний план (нужен токен активации, `xdg-activation`).
- Щелчок из Центра уведомлений Windows не проверен.
- Работа фронтенда в скрытом окне (проверки в фоне, правила) ещё не проверена вживую.
