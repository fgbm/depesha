Решение #24 и что с ним делает каждый вариант
Что решили в 0.6.0 (#24)Формат письма — в меню «⋯» нижней панели, над «Сохранить черновик»; текущий отмечен галочкой. Причина: формат одного письма меняют редко, а режим «Текст» вообще без строки оформления.
Что меняется теперьС Live Preview HTML и Markdown выглядят почти одинаково, и спрятанный формат стал проблемой: не понять, почему тут звёздочки. Оператор решил вывести формат на экран кнопкой, которая его и показывает.
А — противоречит #24 сильнее всехФормат уезжает из подвала наверх. В режиме «Текст» строки оформления нет — значит, ради переключателя появляется строка с одним переключателем.
Б — ближе всех к #24Формат остаётся в подвале, рядом с «⋯», только вынесен из меню в собственную кнопку с подписью. Подвал есть во всех трёх режимах. Пункты формата из «⋯» уходят — дублировать незачем.
В — тумблер на три состояния не ложитсяHTML ↔ Markdown одним щелчком, «Текст» остаётся в «⋯». В режиме «Текст» строки оформления нет, тумблера тоже — индикатор пропадает ровно там, где непонятнее всего.
  • 1А, сегменты в строке оформления. Плюсы: видно все три формата сразу, переключение в один щелчок, привычно по переключателю над входящим письмом (#8). Минусы: занимает ~200 px в строке, где и так тесно (в узком окне не помещается — придётся сворачивать в кнопку с меню, то есть в Б); в режиме «Текст» нужна строка ради одного переключателя; формат уезжает из подвала, вопреки #24.
  • 2Б, кнопка с меню в подвале. Плюсы: одно место во всех трёх режимах и при любой ширине (в узком окне — значок без подписи); меню то же, что было в «⋯» по #24, плюс строка о правиле для адресата (#44); строка оформления не меняется. Минусы: два щелчка до смены; подвал — не там, куда смотрят во время набора; подпись видна, но тише, чем сегменты.
  • 3В, тумблер. Плюсы: самый короткий элемент, читается как «Markdown включён». Минусы: третий формат прячется в «⋯», в режиме «Текст» индикатора нет; тумблер обещает «вкл/выкл», а не выбор из трёх.
  • 4Рекомендую Б: он выводит формат на экран и при этом меньше всех ломает решение #24 — формат по-прежнему живёт в подвале рядом с «⋯», просто стал видимым. В меню «⋯» остаются «Сохранить черновик» и «Удалить черновик».
  • 5Место в подвале: кнопка формата (~120 px) плюс «Без напоминания» из #37 не помещаются в окно ~600 px. В кадрах Б напоминание убрано ради места; в приложении первым теряет подпись «Файлы» (как в узком окне сейчас), потом кнопка формата становится значком предложение.
  • 6Сочетания клавиш для смены формата по-прежнему нет (#24): действие редкое. Команда «Формат письма: Markdown» и другие — в палитре Ctrl+K и в редакторе клавиш (#46), если кто-то захочет назначить.

Правила
Что происходит с уже набранным текстом
1

2

4
Markdown → Текст. Без вопроса (#24): знаки разметки остаются символами. Картинки из текста становятся вложениями — об этом тост.
5
Текст → HTML / Markdown. Без вопроса. В Markdown набранные звёздочки сразу станут оформлением — это и есть смысл перехода.

  • 2Б, подпись в Markdown. У подписи свой формат — переключатель «HTML · Markdown» в её карточке; Markdown-подпись правится Live Preview-редактором, из неё строятся HTML и текст. Плюсы: тем, кто пишет только в Markdown, всё одинаково; Markdown-часть точно такая, как написана. Минусы: второй редактор подписи и ещё один переключатель; подпись в Markdown всё равно ставится и в HTML-письма — значит, логотип только отдельной строкой.
  • 3Третий вариант — разные версии подписи для HTML и Markdown — не рисую: три версии одной подписи (с текстовой) никто вести не будет.
  • 4Рекомендую А: задача решается без нового редактора, а Live Preview для подписи можно добавить потом, если попросят.
