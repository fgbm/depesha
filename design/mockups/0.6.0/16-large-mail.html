#16 · Поиск крупных писем

Макеты к #16 «Поиск крупных писем». Размер в строке, операторы размера и возраста, готовые запросы в подсказках поиска и в Ctrl+K, итоги «N писем · объём», массовое удаление. Решение принято: готовые фильтры — это операторы + готовые запросы, без новых пунктов боковой панели и без сохранённых поисков. Ярлык предложение — деталь, которой нет в задаче.

Основа: сортировка «Крупные сначала» (src/lib/sort.ts, ViewMenu.svelte), операторы crates/depesha-core/src/query.rs (from: to: subject: has:attachment is: before: after: in: и русские синонимы), палитра plugins/command-palette.

Предлагаемые операторы предложение — в духе существующих, с русскими синонимами:
larger:25M / больше:25M (также 25МБ, 500K, 1G) · smaller: / меньше: · older:1y / старше:1г (6m/6мес, 30d/30д) · newer: / новее: · year:2024 / год:2024 = после:2024-01-01 до:2025-01-01 · in:Работа/* / в:Работа/* — с подпапками · account: / ящик: — один ящик.
На сервер (IMAP SEARCH) уходят как LARGER, SINCE/BEFORE; /* — несколько папок по очереди.
