Страница ящика в настройках — 0.6.0

Новая структура страницы ящика в едином окне «Настройки» (сейчас — Wizard.svelte в режиме embedded внутри Preferences.svelte). Решено: одна прокручиваемая страница с разделами и оглавлением-якорями; поля подключения свёрнуты в «Общем»; каждая функция заполняет свой раздел. ← все макеты 0.6.0

1Страница ящика, начало: «Общее» и свёрнутое «Подключение»

Одна прокручиваемая страница вместо нынешней формы мастера. Наверху — оглавление-якоря Общее · Письма и подписи · Хранилище · Сервер; оно прилипает к верху при прокрутке и подсвечивает раздел, который сейчас на экране. В «Общем» — название, имя отправителя, адрес, цвет (сейчас цвет живёт только на странице «Все ящики») и папка для вложений. Поля сервера свёрнуты в «Подключение»: в заголовке — одна строка-сводка и состояние, чтобы не раскрывать ради проверки.

Технические подробности

Без паролей, токенов и содержимого писем — можно отправить разработчику.

До входа (приветствие сервера):
* OK [CAPABILITY IMAP4rev1 SASL-IR LOGIN-REFERRALS ID ENABLE IDLE LITERAL+ AUTH=PLAIN AUTH=LOGIN] mail.example.com ready.
После входа:
* CAPABILITY IMAP4rev1 SASL-IR LOGIN-REFERRALS ID ENABLE IDLE SORT SORT=DISPLAY THREAD=REFERENCES THREAD=REFS THREAD=ORDEREDSUBJECT MULTIAPPEND URL-PARTIAL CATENATE UNSELECT CHILDREN NAMESPACE UIDPLUS LIST-EXTENDED I18NLEVEL=1 CONDSTORE QRESYNC ESEARCH ESORT SEARCHRES WITHIN CONTEXT=SEARCH LIST-STATUS BINARY MOVE SNIPPET=FUZZY PREVIEW=FUZZY PREVIEW STATUS=SIZE SAVEDATE LITERAL+ NOTIFY SPECIAL-USE QUOTA APPENDLIMIT=52428800
Сеанс синхронизации:
C: ENABLE QRESYNC
S: * ENABLED QRESYNC
Неизвестны Депеше (сохранены, но не считаются функциями):
SASL-IR LOGIN-REFERRALS MULTIAPPEND URL-PARTIAL CATENATE I18NLEVEL=1 ESORT SEARCHRES WITHIN CONTEXT=SEARCH BINARY SNIPPET=FUZZY PREVIEW=FUZZY PREVIEW SAVEDATE NOTIFY

  • 2Кнопки внизу — общие для всей страницы. «Сохранить» становится «Проверить и сохранить», только если менялись поля «Подключения» (см. кадр 4): переподключение нужно не всегда. предложение
  • 3«Подпись» из нынешней формы переезжает в «Письма и подписи», «Сохранять копию отправленных» — внутрь «Подключения» (она про сервер).

Технические подробности

Без паролей, токенов и содержимого писем — можно отправить разработчику.

До входа (приветствие сервера):
* OK [CAPABILITY IMAP4rev1 SASL-IR LOGIN-REFERRALS ID ENABLE IDLE LITERAL+ AUTH=PLAIN AUTH=LOGIN] mail.example.com ready.
После входа:
* CAPABILITY IMAP4rev1 SASL-IR LOGIN-REFERRALS ID ENABLE IDLE SORT SORT=DISPLAY THREAD=REFERENCES THREAD=REFS THREAD=ORDEREDSUBJECT MULTIAPPEND URL-PARTIAL CATENATE UNSELECT CHILDREN NAMESPACE UIDPLUS LIST-EXTENDED I18NLEVEL=1 CONDSTORE QRESYNC ESEARCH ESORT SEARCHRES WITHIN CONTEXT=SEARCH LIST-STATUS BINARY MOVE SNIPPET=FUZZY PREVIEW=FUZZY PREVIEW STATUS=SIZE SAVEDATE LITERAL+ NOTIFY SPECIAL-USE QUOTA APPENDLIMIT=52428800
Сеанс синхронизации:
C: ENABLE QRESYNC
S: * ENABLED QRESYNC
Неизвестны Депеше (сохранены, но не считаются функциями):
SASL-IR LOGIN-REFERRALS MULTIAPPEND URL-PARTIAL CATENATE I18NLEVEL=1 ESORT SEARCHRES WITHIN CONTEXT=SEARCH BINARY SNIPPET=FUZZY PREVIEW=FUZZY PREVIEW SAVEDATE NOTIFY
