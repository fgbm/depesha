Письма с подписями DKIM, на которых проверяется своя проверка отправителя.

Файлы `001.txt`–`006.txt` взяты из `mail-auth` 0.13.3 (`resources/dkim/`, проект Stalwart Labs LLC) без изменений. Лицензия — Apache-2.0 или MIT на выбор, тексты в этой папке. Это настоящие письма и их настоящие подписи: RFC 8463 (ed25519), RFC 6376 (пример `football.example.com`), рассылки ietf.org, github.com, facebookmail.com, topicbox.com.

Формат файла: записи DNS (по строке `<имя> <значение>`) до пустой строки, дальше само письмо. Записи публикуются в кэш проверки вместо обращения к сети, поэтому тест не ходит в DNS.

`crates/depesha-core/src/dkim.rs` проверяет по ним ступени 3 и 4 лестницы. Ступень 4 проверяется по тем же файлам с отрезанным телом: подпись покрывает заголовки, и хэш тела ей больше не нужен.
